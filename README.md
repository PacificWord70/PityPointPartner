# User-Installable app for Discord

This project contains a basic example of a game integration for Discord written in JavaScript, built for the [Developing a User-Installable App tutorial](http://discord.com/developers/docs/tutorials/developing-a-user-installable-app).

---
This is the PityPointPartner app that the Street Rats guild in Throne of Liberty used.
The JSON files are examples of formatting since I did not want to include member's Discord ID numbers. (Just remove "-example" from the files)
Also the role ID number need to be changed to work as intended.

This project is being discontinued since the guild has merged.
Long live Street Rats :)
